# Hakkım Var

Hakkım Var, dört alt menüye sahip bir Expo / React Native tüketici hakları uygulamasıdır:

- Ana sayfa
- Modüller
- Başvurular
- Profil

Modüller ekranında ürün kusuru analizi, hak ve mevzuat rehberi, belge hazırlama,
firma ihtarları, TÜBİS başvuru rehberi ve ürün/içerik analizi araçları bulunur.

## Get started

Bağımlılıkları `npm install` ile yükleyin, ardından uygulamayı başlatın:

```bash
npx expo start
```

Uygulama Expo Router kullanır. Ekran rotaları `src/app/`, özellik düzenleri ve
modül kartları `src/features/` klasöründedir.
